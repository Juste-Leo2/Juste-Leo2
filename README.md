### 🚀 Main Project: SpinalML
**[SpinalML](https://github.com/Juste-Leo2/spinalML)** is an open-source framework for generating AI hardware accelerators on FPGA (based on SpinalHDL). 
- **Hardware Demo**: [Real-time inference (MNIST W4A8)](https://github.com/Juste-Leo2/mnist-w4a8-spinal-fpga) on a Tang Primer 20K board with a web interface.
